# Go Kurious Gemini

A public collection built only from the 15 React activity code sections printed in the uploaded Go-Kurious PDF.

Live site:

https://rakeshranjan-commits.github.io/go-kurious-gemini/

The source files under src/activities preserve each PDF code section as a separate component. The two Food Chain sections remain separate because they appear as separate blocks in the PDF.

The original Go-Kurious-Gemini-Source.pdf is included and deployed with the site.

## Publishing

Vite builds the public site into docs. GitHub Pages serves the docs folder from the main branch.
